# Zync - All-in-One Super App

Zync is a modern multi-purpose super app built with Flutter. It combines secure authentication, real-time messaging, social feed sharing, and digital wallet management all in one place.

## Features:
- 📱 **OTP Login/Signup**
- 💬 **WhatsApp Style Real-time Chat**
- 📰 **Facebook Style Social Feed & Posting**
- 💸 **GPay/Paytm Style Wallet & Payments**
- ⚙️ **Language & Country Selection Settings**
